Deployment Reference

Build & Push Docker Image
# Always use --no-cache (stale layers cause silent bugs) snow spcs image-registry login --connection eu_demo200 docker build --no-cache --platform linux/amd64 \ -t supermario ./mario-spcs/ docker tag supermario \ sfseeurope-eu-demo200.registry.snowflakecomputing.com/mario_db/public/mario_repo/supermario:latest docker push \ sfseeurope-eu-demo200.registry.snowflakecomputing.com/mario_db/public/mario_repo/supermario:latest
Service Lifecycle
# Resume (use ALTER SERVICE to force new image pull) snow spcs compute-pool resume MARIO_POOL --connection eu_demo200 snow sql --role ACCOUNTADMIN -q "ALTER SERVICE MARIO_DB.PUBLIC.MARIO_SERVICE FROM SPECIFICATION \$\$ spec: ... \$\$" # Suspend everything snow spcs service suspend MARIO_DB.PUBLIC.MARIO_SERVICE --connection eu_demo200 snow spcs compute-pool suspend MARIO_POOL --connection eu_demo200 # React local dev PORT=3456 npm run dev --prefix mario-react-app # Deploy Streamlit uvx --from snowflake-cli snow streamlit deploy \ --replace --connection eu_demo200 --role ACCOUNTADMIN

Key Learnings

🐳
Always use --no-cache for Docker builds. Docker silently reuses stale cached layers even when file content has changed. Without --no-cache, code changes may not make it into the image.
🔄
suspend/resume does NOT re-pull the image. Use ALTER SERVICE FROM SPECIFICATION to force SPCS to pull the latest image digest.
🔐
Use snow spcs image-registry login for Docker auth. Direct docker login requires MFA+TOTP as a combined string; the snow CLI handles this automatically.
📍
nginx location = /telemetry (exact match) is critical. A prefix match catches /telemetry.js, routing the JS file to the sidecar instead of Tomcat.
📦
Bundle all JS dependencies inside the Docker image. SPCS blocks external egress — CDN URLs fail silently. jQuery and other libs must be served locally from Tomcat.
📡
Use GET tracking pixel, not POST, for telemetry. SPCS ingress may block browser POST requests. new Image().src = url is reliable, includes auth cookies, and works cross-origin.
👤
Browser must include player_name in every event payload. The sidecar's header-based extraction alone is insufficient — telemetry.js must call /whoami and include the name in each send() call.
⚡
Interactive Tables use CREATE INTERACTIVE TABLE syntax (not CREATE DYNAMIC INTERACTIVE TABLE). Associate with IWH via ALTER INTERACTIVE TABLE ... SET WAREHOUSE = <IWH>.
🔑
EXTERNALBROWSER auth does NOT work in headless Node.js. React API routes must use SNOWFLAKE_JWT (keypair) auth. The private key path must be absolute.
🧠
Use $ as dollar-quote delimiter for CREATE AGENT FROM SPECIFICATION (not $spec$). FastGen query ID must be stored immediately via SET before any subsequent queries.
